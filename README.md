# HeavyDuty

App de Android para registrar tus entrenamientos de fuerza: rutinas, series, descansos, récords personales y estadísticas.

> **Versión beta.** Es una versión de prueba para amigos; puede tener errores.

## Descargar

**[⬇️ Descargar HeavyDuty.apk](https://github.com/Waldoz-X/HeavyDuty/releases/latest/download/HeavyDuty.apk)** — versión 0.1.2

El enlace siempre baja la versión más reciente. Todas las versiones y sus cambios están en [Releases](https://github.com/Waldoz-X/HeavyDuty/releases).

### Cómo instalarla

1. Abre el enlace de arriba **desde tu teléfono Android** (Android 7.0 o superior).
2. Cuando termine la descarga, toca el archivo `HeavyDuty.apk`.
3. Si Android avisa que no puede instalar apps de esa fuente, toca **Configuración** y activa **Permitir de esta fuente** (para Chrome o Archivos). Luego vuelve e instala.
4. Si Play Protect muestra una advertencia, toca **Más detalles → Instalar de todas formas**. Pasa porque la app no viene de Play Store.

### Actualizar

Descarga e instala el APK nuevo encima del anterior. No hace falta desinstalar, y tus datos se conservan.

### Tus datos

Todo se guarda solo en tu teléfono; la app no tiene cuentas ni servidor. Si vas a cambiar de teléfono o desinstalar, primero haz un respaldo en **Perfil → Tus datos → Exportar**.
